#  Restaurante Online

Sistema web para gestão e apresentação de um restaurante, desenvolvido como projeto prático de desenvolvimento web, com integração a base de dados e área administrativa.

##  Sobre o projeto

O **Restaurante Online** é uma aplicação web desenvolvida para simular a operação digital de um restaurante.

A aplicação possui uma área pública para consulta do cardápio, realização de pedidos, reservas e contacto, além de uma área administrativa destinada à gestão do restaurante.

O projeto foi desenvolvido durante a minha formação em programação e faz parte do meu portfólio de desenvolvimento web.

##  Funcionalidades

### Área pública

*  Página inicial
*  Consulta do cardápio
*  Realização de pedidos
*  Finalização de pedidos
*  Sistema de reservas
*  Página de contacto

### Área administrativa

*  Autenticação de administrador
*  Dashboard administrativo
*  Gestão de colaboradores
*  Gestão de pratos e produtos
*  Gestão de categorias
*  Gestão de estoque
*  Gestão de pedidos
*  Gestão de reservas
*  Visualização de pratos populares
*  Exportação de informações para PDF
*  Exportação de informações para Excel
*  Operações CRUD

### API

O projeto também possui endpoints em PHP para disponibilizar e processar dados relacionados ao cardápio, estoque e pedidos.

##  Como executar o projeto

### 1. Pré-requisitos

Para executar o projeto localmente, é necessário ter instalado:

* [XAMPP](https://www.apachefriends.org/)
* PHP
* MySQL
* Navegador web

### 2. Clonar o repositório

```bash
git clone https://github.com/DevNelson16/Restaurante-Online.git
```

### 3. Colocar o projeto no XAMPP

Coloque a pasta do projeto dentro de:

```text
C:\xampp\htdocs\
```

A estrutura deverá ficar semelhante a:

```text
C:\xampp\htdocs\gestao_restaurante\
```

### 4. Iniciar o XAMPP

No painel do XAMPP, inicie:

* Apache
* MySQL

### 5. Configurar a base de dados

Abra o **phpMyAdmin** através do XAMPP e configure a base de dados utilizada pela aplicação.

Caso o repositório contenha um ficheiro `.sql`, importe-o através do phpMyAdmin.

Verifique também as configurações de ligação à base de dados no ficheiro:

```text
includes/db.php
```

### 6. Executar a aplicação

Abra o navegador e aceda a:

```text
http://localhost/gestao_restaurante/
```
